# Design audit

Copies of the four ledger pages (Pokémon TCG, Lorcana, Wrestling, Football) with all scripts and data stripped out, so only styles and static markup are public. Run **Design audit (Impeccable detector)** from the Actions tab after a redesign; results land in `source.json` and `rendered_*.json`.

Refresh the copies after a ledger change, stripping `<script>` blocks again before committing.
